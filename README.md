# Max Heap Search Visualizer

一個純 HTML、CSS、JavaScript 的互動式最大堆積與搜尋比較工具。直接開啟 `index.html` 即可使用。

## 功能

- 輸入整數數列，自動建立 Max Heap 並繪製堆積樹。
- 逐筆新增整數，或清空堆積。
- 使用 Max Heap 性質剪枝搜尋目標值，並在樹上標示檢查路徑。
- 將數列複製後以氣泡排序排序，再用二分搜尋尋找目標值。
- 顯示比較次數、交換次數、堆積大小、樹高、葉節點數與時間複雜度。

## 時間複雜度

| 方法 | 最佳 | 平均／最差 | 額外空間 |
| --- | --- | --- | --- |
| Max Heap 搜尋（利用堆積性質剪枝） | O(1) | 最差 O(n) | 最差 O(n) |
| 氣泡排序後二分搜尋 | 排序最佳 O(n)，整體 O(n) | 排序 O(n²)，二分搜尋 O(log n)，整體 O(n²) | O(n) |

Max Heap 只保證父節點不小於子節點，並非二元搜尋樹，因此一般搜尋最差仍須檢查 O(n) 個節點。氣泡排序法會先排序資料副本，不會改變畫面上的堆積。
